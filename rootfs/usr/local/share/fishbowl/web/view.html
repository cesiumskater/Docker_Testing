Restore a backup (.sql)

Upload the file on the Fishbowl page first.

  1. Restore tab → the magnifier next to Restore File → double-click import → your file → Open.
  2. Database: check the name. A new name is the safe choice; an existing name is replaced.
  3. Password: leave it as it is. Fishbowl fills it in, and that's already the right one (it's never shown).clear it and type the MySQL root password you chose when this installation was set up.
  4. Restore → Yes → wait for "Database has been restored." → OK.
  5. Database tab → click the restored database in the list → OK → OK.

Cleared the password by mistake? Close Server Administration (Cancel) and open it again from the Fishbowl page, and Fishbowl fills it in again.

Create a new database

  1. Database tab → green +.
  2. A database name (letters, numbers, underscores). Leave Password as Fishbowl filled it inClear Password and type the MySQL root password you chose when this installation was set up → Connect.
  3. Choose your country and costing method (this can't be changed later) → OK, and wait.
  4. OK → OK.

Cleared the password by mistake? Click Cancel and + again, and Fishbowl fills it in again.

Changed something while Fishbowl Server is running? It takes effect after Restart Fishbowl Server on the Fishbowl page.

The Fishbowl Client

This is the Client installed inside the container, connected to the Fishbowl Server next to it. Everyone who opens this page shares this one window.

Closing the Client's own window ends it. You can open it again from the Fishbowl page.
