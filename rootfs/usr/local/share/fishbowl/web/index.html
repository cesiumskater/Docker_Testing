Can't reach the container

The page lost its connection. If the container is stopped or restarting, this page picks up again by itself once it's back (docker ps shows whether it's running).

You're using this page over the network

This connection isn't encrypted, so the access code and anything you type in the Fishbowl windows could be read by others on the network. The safe way is to open the page on the computer that runs Docker, at http://localhost:6080/, and publish the port as 127.0.0.1:6080:6080.

This container has no named volumes

Docker gave it unnamed volumes. Fishbowl works on them, but they belong to this one container: a new container won't find them by itself, and removing this container together with its volumes deletes your Fishbowl install and database.

The container's log (docker logs) has the two commands that fix this: one to start over with named volumes, one to keep the data you already have here.

Your company database

    
Fishbowl is installed. Fishbowl Server starts by itself as soon as a company database is selected, and that happens in Fishbowl Server Administration, which opens in its own browser tab. Do you have a Fishbowl backup (a .sql file) to restore?

    

      

        
Yes: restore a backup

        

        
    
          
  1. Upload the .sql file in the box below.
    2. 
          
  2. Open Server Administration and go to the Restore tab.
    3. 
          
  3. Click the magnifier next to Restore File, double-click the import folder, pick your file and click Open.
    4. 
          
  4. Database: Fishbowl fills in a name from the file name. Check it, or type the name you want (letters, numbers and underscores).
    5. 
          
  5. Password: leave it as it is. Fishbowl fills it in, and that's already the right one (it's never shown).clear it and type the MySQL root password you chose when this installation was set up. Host localhost, Port 3306 and Username root stay as they are.
    6. 
          
  6. Click Restore, confirm with Yes, and wait for "Database has been restored." A large database takes a while. Click OK.
    7. 
          
  7. Go to the Database tab. The restored database is in the list. Click it, then OK, and OK again on "Database Connection has been changed".
    8. 
        

      

      

        
No: create a new one

        
    
          
  1. Open Server Administration. On the Database tab, click the green + on the right.
    2. 
          
  2. Database: a name for your company database (letters, numbers and underscores). Host localhost, Port 3306, Username root.
    3. 
          
  3. Password: leave it as it is. Fishbowl fills it in, and that's already the right one (it's never shown).clear it and type the MySQL root password you chose when this installation was set up. Click Connect.
    4. 
          
  4. Fishbowl asks for your country and costing method. Fishbowl warns that this can't be changed later. Click OK and wait while Fishbowl creates the database.
    5. 
          
  5. Click OK to save, then OK on "Database Connection has been changed".
    6. 
        

      

    

    
Server Administration closes after the last OK, and this page shows Fishbowl Server starting.

      How to restore one while Fishbowl Server is running
      
    
        
  1. Open Server Administration, Restore tab. Click the magnifier next to Restore File, double-click the import folder, pick the file, Open.
    2. 
        
  2. Database: check the name Fishbowl filled in. A new name restores the backup next to your current database, which is the safe choice. An existing name replaces that database: everything in it that isn't in the backup is lost.
    3. 
        
  3. Password: leave it as it is. Fishbowl fills it in, and that's already the right one (it's never shown).clear it and type the MySQL root password you chose when this installation was set up. Click Restore, confirm with Yes, wait for "Database has been restored."
    4. 
        
  4. To switch Fishbowl to the restored database: Database tab, click it in the list (the restore put it there), OK, and OK on the message that follows. Then press Restart Fishbowl Server on this page.
    5. 
      

      
Replacing the database Fishbowl Server is using right now? Press Stop Fishbowl Server first, restore over it, click Cancel to close Server Administration, then press Start Fishbowl Server.

      
A backup made by an older Fishbowl version is updated by Fishbowl Server the first time it starts on it. A trial installation can't do that: Fishbowl refuses with "Trial accounts do not have access to update the database." The list above shows which Fishbowl version made each file. A zipped backup needs unzipping first, because the Restore tab lists .sql files.

      Good to know
      
    
        
  • Fishbowl Clients on other computers connect to this computer's name or IP address on the client port published by Docker (2456 unless you changed it).
    • 
        
  • The Fishbowl Client button opens the Client that's installed inside the container, in a browser tab. There is one of it, and everyone who opens it shares the same window, so it suits the person who looks after the server. Everyone else installs the Fishbowl Client on their own computer.
    • 
        
  • Server Administration is where you choose the company database, enter a license, change server settings and restore backups. Click OK or Cancel inside it to close it.
    • 
        
  • This page's link, with its access code: docker exec fishbowl fishbowl-link
    • 
        
  • A backup of everything in MySQL: docker exec -it fishbowl fishbowl-backup
    • 
        
  • The log: docker logs -f fishbowl
